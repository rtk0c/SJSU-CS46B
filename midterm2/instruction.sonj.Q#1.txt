QUESTION 1 (15 points):

Create class Ship with 3 variables:
  long price
  String identity
  double length

* In package mt2, create class Fleet which aggregates (collects) instances of Ship. 
* All instances in a Fleet should be unique according to deep-equals. 
	* That is, if a and b are both in a Fleet, then a.equals(b) must always be false. 
* Your Fleet should provide the following methods.
	* If any of the methods is provided by a superclass, you don't have to write the method if you don't want to.

  	* public boolean add(Ship x) - 
		If this Fleet contains anything that is deep-equal to x, returns false.
    	Otherwise adds x to this Fleet and returns true.

  	* public boolean contains(Ship x) - 
		If this Fleet contains anything that is deep-equal to x, returns true.
    	Otherwise returns false.

  	* public ArrayList<Ship> toSortedList() - 
		Returns an ArrayList containing all Ship instances in the Fleet, in sorted order. 
		Sorting should first consider price, then identity, then length.
