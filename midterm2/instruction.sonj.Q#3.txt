QUESTION 3 (20 points):

In package mt2, create classes LinkedListNode<T> and GenericLinkedList<T> to implement a generic linked list. 

The node should have a variable of type T to hold its data. 

It should provide the following methods:
  * replicateHead() - 
	Creates a node with data identical to the head of the list. 
	Inserts the new node either just before or just after the head of the list.
	Does nothing if the list is empty.

  * replicateTail() - 
	Creates a node with data identical to the tail of the list. 
	Inserts the new node either just before or just after the tail of the list.
	Does nothing if the list is empty.

  * find(T findThis1, T findThis2, T findThis3) - 
	Returns a node where:
      * The data of the returned node is deep-equal to findThis1.
      * The data of the node after the returned node is deep-equal to findThis2.
      * The data of the node after the node after the returned node is 
		deep-equal to findThis3
      * If no nodes meeting these conditions are found, find should return null.

  * checkHeadTail() - 
	return true if head and tail are either both null or both non-null pointers.
	return false otherwise.

  * checkLoop() - 
	return true if there does NOT exist a loop.
	return false otherwise.
